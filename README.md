# Student Marks Calculator

## 1. Project Description

Student Marks Calculator is a C++ console application that calculates a student's total marks, average, and pass/fail result.

## 2. Project Objectives

- Calculates total marks.
- Calculates average marks.
- Determine the student's grade.
- Determine whether the student passed or failed.
- Validate marks entered by the user.


## 3. Technologies Used

- C++
- Visual Studio Code
- GCC Compiler

## 4. features 

- Student name input.
- five subject marks.
- Total marks Calculation.
- Average Calculation.
- Automatic grade determination.
- Pass/fail result.
- Basic mark validtion.

## 5. subjects

- The application uses five subjects:

1. English 
2. Mathematics
3. Computer 
4. Somali
5. Science

Each subject has a maximum score of 100.

## 6. Grading Sustem

Average   Grade   Result
------------------------
80-100     A       Pass
70-79      B       Pass
60-69      C       Pass
50-59      D       Pass
0-49       F       Fail

## 7. How to Compile

Open the project folder in the terminal and run:

g++ main.cpp -o student.exe

## 8. How to Run 
On Windows Powershell, run:

.\student.exe
